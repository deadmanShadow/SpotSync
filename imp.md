# SpotSync — Project Descriptions

## LinkedIn Description (50–60 words)
Built SpotSync, a smart parking and EV charging reservation platform designed to help drivers find available spaces, reserve spots before arrival, and manage bookings effortlessly. The platform provides live availability updates, secure user access, reliable reservation handling, and a dedicated administration experience for managing parking zones, pricing, users, and reservations across busy airports and malls.

## GitHub Description (10–15 words)
Smart parking and EV charging reservation platform with real-time availability and admin management.
